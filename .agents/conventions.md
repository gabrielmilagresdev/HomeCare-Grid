# Convenções

TypeScript strict; componentes PascalCase, funções camelCase, exports nomeados exceto rotas. Imports relativos/@/; domínio usa extensão .ts para testes Node. Preferir unions literais.

IDs UUID no backend, demo-* em fixtures. Centavos inteiros BRL. ISO UTC Z; exibição America/Sao_Paulo. Intervalos [início,fim). UI em português simples.

Antes de dependência: verificar fonte oficial e Expo Go, justificar, instalar com expo install quando aplicável, fixar versão e atualizar lockfile em alteração serializada. Sem módulos customizados, experimentais ou responsabilidades duplicadas.
