# Definition of Done

- Issue/aceite demonstrados e dependências integradas.
- Escopo pequeno, contratos revisados/consumidores compatíveis.
- npm ci, typecheck, lint, testes relevantes, doctor e bundle no SHA atual.
- Loading/empty/error e acessibilidade quando houver UI.
- Sem segredos/dados reais; autorização, RLS/concorrência quando aplicáveis.
- Docs atualizadas, limitações explícitas, revisão independente.
- Integração pelo árbitro validada antes de fechar Issue.
